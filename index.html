Los empleados existentes no se eliminan automáticamente. Para cambiar exclusiones, revisaremos un flujo con confirmación y auditoría.

Períodos de trabajo

Crear período

Los períodos sirven para organizar turnos, firmas y documentos.

Registro manual de horarios y firmas

Ingresa una jornada por empleado y fecha. Los turnos nocturnos que terminan al día siguiente se reconocen automáticamente. Las horas de comida no se descuentan.

Comparación de horas

Solo se calculan diferencias cuando existen horarios y firmas completos y aprobados. Los registros pendientes se identifican, no se convierten en cero. CSV compatible con Excel; el formato XLSX llegará después.

Documentos privados

Guarda PDF o fotografías de horarios y firmas en el almacenamiento privado. La extracción automática todavía no está disponible.

Lectura asistida · revisión obligatoria

Lee texto seleccionable de un PDF en tu dispositivo o abre una imagen para transcribirla. No realiza OCR de fotografías ni reconoce firmas manuscritas. Ningún dato se guarda automáticamente.

El texto de un PDF puede venir desordenado. Verifica siempre fechas, nombres, horas y la página original. Para fotografías, escribe manualmente los datos que puedas leer.

Posibles jornadas (sin guardar)

Selecciona una propuesta y confirma los datos en la pestaña Horas. Si hay dudas, deja el registro pendiente.
